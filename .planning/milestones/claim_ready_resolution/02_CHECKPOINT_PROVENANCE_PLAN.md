## When Path A Would Not Be Enough

Path A would not be enough if:

- strict readiness requires clean source-row provenance, because the selected
  formal rows record `git_dirty=true`;
- sidecar content must prove training provenance that cannot be reconstructed
  from existing files;
- missing row schema fields must be present in original source rows rather
  than in a separately authorized derived package;
- empirical performance blockers remain central to claim readiness.

Those cases require Phase 15/16 routing to Path B or Path C. Phase 14 does not
choose that route.
