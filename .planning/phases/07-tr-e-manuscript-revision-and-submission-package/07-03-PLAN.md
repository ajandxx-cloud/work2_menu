# Plan 03 - Revision Summary, Prohibited-Language Scan, And Verification Closeout

<objective>
Close Phase 7 by polishing the revised manuscript, creating the lean revision
summary and revised prohibited-language check, running manuscript-focused
verification, and recording whether the revised manuscript remains within the
conditional diagnostic claim ceiling.
</objective>

<scope>
In scope:
- Perform final consistency edits to `TR_E_WORK2_MANUSCRIPT_REVISED.md` after
  Plans 01 and 02.
- Create `manuscript/TR_E_WORK2_REVISION_SUMMARY.md`.
- Create `manuscript/TR_E_WORK2_REVISED_PROHIBITED_LANGUAGE_CHECK.md`.
- Run import smoke, manuscript claim guard test, manuscript readiness package
  test, file existence checks, source-map checks, and prohibited-language scan.
- Record whether the source map changed or remained unchanged.

Out of scope:
- Running or regenerating evidence.
- Broad new readiness audit package beyond the lean summary/check deliverables.
- Editing generated rows, package status, package indexes, claim guards,
  generated tables/figures, or artifact mirrors.
- Claim-ready empirical submission classification.
</scope>

<must_haves>
<truths>
- D-04: The revised manuscript must be complete from Abstract through Appendix.
- D-13: Deliverables stay lean.
- D-14: Source-map update decision is explicit.
- D-15: Generated evidence stays untouched.
- D-16: Verification includes manuscript-focused checks and baseline runtime
  import/claim/readiness checks.
</truths>
</must_haves>

<threat_model>
| Threat | Severity | Mitigation |
| --- | --- | --- |
| Final polish introduces prohibited positive language | high | Run the exact prohibited-language scan and classify every hit |
| Verification records are vague | medium | Record command, PASS/FAIL, and short output summary in revision summary |
| Source-map update decision is forgotten | medium | Include a dedicated source-map decision section in the revision summary |
| Manuscript readiness test still targets the Phase 5 draft only | medium | Run it as a baseline package contract, then supplement with root checks against the revised manuscript |
| Generated evidence is touched during closeout | high | Review `git diff --name-only` and confirm changed files are Phase 7 manuscript/planning artifacts only plus any approved source-map update |
</threat_model>
