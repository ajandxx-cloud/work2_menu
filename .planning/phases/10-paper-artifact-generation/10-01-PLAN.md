# Phase 10 Plan 1: Paper Artifact Package Index

<objective>
Create the Phase 10 paper artifact package assembler. The assembler should
index existing generated evidence into a minimal main-paper package plus a
diagnostic appendix package, while preserving source paths, statuses,
claim-linkage metadata, and current `claim_ready=false` boundaries.
</objective>

<scope>
## In Scope

- Add `work2_coding/Src/paper_artifacts.py`.
- Add `work2_coding/scripts/build_phase10_paper_artifacts.py`.
- Add `work2_coding/scripts/test_phase10_paper_artifacts.py`.
- Index main RC artifacts, Phase 8 sensitivity artifacts, Phase 9 tractability
  artifacts, formal blocker documents, and case scaffold files.
- Write package metadata under:
  `work2_coding/artifacts/work2_robust_menu/phase10_paper_artifacts/`.
- Mirror lightweight package outputs under:
  `artifacts/work2_robust_menu/phase10_paper_artifacts/`.
- Ensure all package items record source path, tier, status, claim linkage,
  package role, and claim readiness.

## Out Of Scope

- Running new experiments or replay.
- Rebuilding final/formal evidence.
- Fetching or executing semi-real case-study data.
- Editing generated normalized rows, existing generated tables, existing
  generated figures, or prior generated claim guards by hand.
- Writing manuscript body prose.
- Upgrading claim-ready status.
</scope>

<threat_model>
## Threat Model

| Threat | Severity | Mitigation |
| --- | --- | --- |
| T-10-01: Diagnostic outputs are packaged as claim-ready main evidence | high | Every package item must carry `tier`, `status`, `claim_ready`, and `claim_linkage`; tests assert Phase 8/9 stay diagnostic and false. |
| T-10-02: Case scaffold is treated as case-study result evidence | high | Force `scaffold_only` tier and reject result table/figure roles for `.planning/data/case_studies/` sources. |
| T-10-03: Package silently omits blockers or source paths | high | Tests require `SOURCE_INDEX.json` and `PACKAGE_INDEX.json` to include blocker documents and source paths for every entry. |
| T-10-04: Existing artifacts are mutated during packaging | medium | Copy or reference files into Phase 10 output; do not rewrite source artifact roots. |
| T-10-05: Missing source artifacts are ignored | medium | Emit `blocked_status` package entries with missing path reasons instead of silently dropping required source families. |
</threat_model>
