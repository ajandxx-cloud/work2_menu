# Plan 01 - Evidence Controls And Manuscript Audit Scaffold

<objective>
Build the claim-control and source-traceability scaffold before drafting prose.
This plan creates the table/figure source map, strict claim audit, prohibited
language checklist, and internal-review response shell that Plan 02 must follow
when drafting the full TR-E manuscript.
</objective>

<scope>
In scope:
- Read generated package and claim-guard JSON as evidence sources.
- Create manuscript companion files under `manuscript/`.
- Map planned manuscript tables/figures to source artifact paths, claim IDs,
  claim status, allowed use, and evidence class.
- Create a claim audit for C1 through C8.
- Create a prohibited-language checklist and scan procedure.
- Record unsafe legacy `main.tex` migration decisions and reviewer-risk
  responses.

Out of scope:
- Writing the full manuscript body.
- Running final replay, calibration, checkpoint training, artifact builders, or
  package builders.
- Editing generated rows, package status, package index, artifact maps,
  figures, tables, mirrors, or claim guards.
- Upgrading any claim beyond strict `CLAIM_GUARD.json`.
</scope>

<must_haves>
<truths>
- D-01: Primary manuscript drafting happens in `TR_E_WORK2_MANUSCRIPT_DRAFT.md`, not `main.tex`.
- D-02: `manuscript/main.tex` is migration source only and must not carry forward unsafe framing.
- D-03: Safe migration starts with notation, mathematical model skeleton, MNL/menu objective material, literature references, bibliography material, and Elsevier metadata.
- D-04: `TR_E_WORK2_RESPONSE_TO_INTERNAL_REVIEW.md` records migrated items, removed items, prohibited-language risks, and resolutions.
- D-10: Results lead with claim-gate/status evidence.
- D-14: Every table or figure has source artifact path, claim ID, claim status, allowed use, and evidence class.
- D-18: Experimental design includes paired replay, checkpoint provenance, artifact status, strict claim guard, source-family status, and allowed-use interpretation.
</truths>
</must_haves>

<threat_model>
| Threat | Severity | Mitigation |
| --- | --- | --- |
| Generated claim status is manually upgraded in manuscript companion files | high | Copy status from `CLAIM_GUARD.json`, `PACKAGE_STATUS.json`, and M4B safe claim table; label all positive claims blocked unless guard authorizes them |
| Legacy `main.tex` unsafe framing leaks into the new draft | high | Record unsafe phrases and required rewrites in `TR_E_WORK2_RESPONSE_TO_INTERNAL_REVIEW.md` and `TR_E_WORK2_PROHIBITED_LANGUAGE_CHECK.md` before drafting |
| A table or figure appears without evidence source or claim status | high | Build `TR_E_WORK2_TABLE_FIGURE_SOURCE_MAP.md` first and require Plan 02 to cite only mapped objects |
| Audit files list forbidden words but the manuscript body uses them as claims | high | Separate prohibited-language inventory from body scan results and require Plan 03 to scan the body only |
</threat_model>
