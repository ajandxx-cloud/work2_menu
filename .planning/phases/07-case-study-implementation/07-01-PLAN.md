# Phase 7 Plan 1: Planning-Side Case Study Contract Pack

<objective>
Create the planning-side semi-real case-study contract pack under
`.planning/data/case_studies/`. The contract pack makes the future case
reproducible and auditable while preserving the current gate: no data download,
no matrix build, no runtime manifest, no policy replay, no case-study result
artifacts, and no manuscript claim upgrade.
</objective>

<scope>
## In Scope

- Create the `.planning/data/case_studies/` directory and human-readable file map.
- Define dual-route source contracts for public OSM/open-network and
  Yanjiao/Beijing motivated routes.
- Define a predeclared route-selection scorecard independent of experiment
  outcomes.
- Define a simulated-demand and simulated-choice protocol placeholder.
- Draft a planning-side case manifest that inherits the seven mainline tags and
  paired-field vocabulary from `formal_robust_menu.yaml`.
- Define a strict reduced-family gate template.
- Write prohibitive future manuscript placeholders only.

## Out Of Scope

- Downloading OSM, GTFS, Overpass, Yanjiao, or other external data.
- Creating raw caches, road graphs, route matrices, simulated demand rows, or
  replay-ready input files.
- Adding any YAML under `work2_coding/Experiments/studies/`.
- Running smoke, pilot, formal, diagnostic, or replay commands for the case.
- Generating normalized rows, paper tables, figures, artifact metadata, or
  claim-upgrade manuscript text.
</scope>

<threat_model>
## Threat Model

| Threat | Severity | Mitigation |
| --- | --- | --- |
| Scaffold is mistaken for empirical evidence | high | Put `scaffolding_only_blocked_execution` and blocker fields in every contract and placeholder. |
| Simulated demand is described as real behavior | high | Force `semi-real`, `simulated demand`, and `simulated choice` labels in every contract and manuscript placeholder. |
| Route or policy-family choice becomes outcome selection | high | Predeclare scorecard criteria and reduced-family gate; prohibit result-based selection. |
| Runtime execution is accidentally enabled | high | Keep all files under `.planning/data/case_studies/` and explicitly forbid runtime manifest YAML. |
</threat_model>
